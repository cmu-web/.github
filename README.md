# .github

Org-wide defaults and shared assets for [CMU Web](https://github.com/cmu-web).
It isn't a project itself.

- `profile/README.md` is the [org's public page](https://github.com/cmu-web).
- `.github/` holds the issue forms and the pull request template. GitHub
  uses them in any repository in the org that doesn't have its own.
- `branding/` holds the org picture's source; its own README says what each
  file is for.
