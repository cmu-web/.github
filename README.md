# .github

Defaults and shared files for the [CMU Web](https://github.com/cmu-web)
organization. It isn't a project itself.

The projects and their docs are listed at
[cmu-web.github.io](https://cmu-web.github.io/).

- [`profile/README.md`](profile/README.md) is the organization's
  [public page](https://github.com/cmu-web).
- [`.github/`](.github/) holds the issue forms and the pull request
  template. GitHub uses them in any of the organization's repositories that
  don't have their own.
- [`DEVELOPMENT.md`](DEVELOPMENT.md) is the setup every project shares; each
  project's own DEVELOPMENT.md starts from it.
- [`SECURITY.md`](SECURITY.md) is how to report a security problem, for every
  repository without its own.
- [`branding/`](branding/) holds the organization's artwork; its README
  lists the files.
