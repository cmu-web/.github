Tools and themes for Carnegie Mellon websites and web apps, built on CMU's
web template.

<!-- projects -->

| Project                                                                 | Repository                                                                              | What It Does                                                                                  |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [Carnegie Mellon Web Kilt](https://webkilt.andrew.cmu.edu)              | [`cmu-web-kilt`](https://github.com/cmu-web/cmu-web-kilt)                               | Components for websites and web apps that use CMU's template.                                 |
| [FencePost](https://fencepost.andrew.cmu.edu/)                          | [`cmu-web-fencepost`](https://github.com/cmu-web/cmu-web-fencepost)                     | Link previews for Carnegie Mellon websites: their image and Open Graph tags.                  |
| [PlaceMellon](https://placemellon.andrew.cmu.edu/)                      | [`cmu-web-placemellon`](https://github.com/cmu-web/cmu-web-placemellon)                 | Placeholder photos of Carnegie Mellon for mockups, plus images ready for live sites and apps. |
| [QRnegie](https://qrnegie.andrew.cmu.edu/)                              | [`cmu-web-qrnegie`](https://github.com/cmu-web/cmu-web-qrnegie)                         | QR codes with Carnegie Mellon character, from Scotty portraits to campus landmarks.           |
| [Forbes & Moreword](https://themes.andrew.cmu.edu/forbes-and-moreword/) | [`cmu-web-forbes-and-moreword`](https://github.com/cmu-web/cmu-web-forbes-and-moreword) | A WordPress theme in CMU style, with the Web Kilt's components ready to insert as patterns.   |
| [Jekyll & Plaid](https://themes.andrew.cmu.edu/jekyll-and-plaid/)       | [`cmu-web-jekyll-and-plaid`](https://github.com/cmu-web/cmu-web-jekyll-and-plaid)       | A GitHub Pages theme that turns plain Markdown into pages in CMU style.                       |

<!-- /projects -->

See them all, and sites that use them, at
[cmu-web.github.io](https://cmu-web.github.io/). For CMU's logos, colors and
template, see [brand.cmu.edu](https://www.cmu.edu/brand/).

For a question or a problem, open an issue in the project's repository.
