# Branding

The organization's artwork, with its sources, so a new version starts from
the original.

| File                                   | What It's For                                                                                                                                                                                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cmu-web-avatar.svg`                   | The source: Scotty in a browser window. The Scotty artwork is PlaceMellon's [`assets/scotty-head.svg`](https://github.com/cmu-web/cmu-web-placemellon/blob/main/assets/scotty-head.svg) (black with the red scarf), with his back continued past the left edge. |
| `org-avatar.png`                       | The 500 × 500 rendering of the source, uploaded as the [organization's picture](https://github.com/organizations/cmu-web/settings/profile).                                                                                                                     |
| `drive-banner.svg`, `drive-banner.png` | The shared Google Drive's banner (1600 × 480, the shape of Drive's themes): CMU red with the Scotty window at the center, where Drive places the drive's round icon.                                                                                            |
| `forms-header.svg`, `forms-header.png` | The Google Forms header (800 × 200), in the same design.                                                                                                                                                                                                        |

Check a new avatar at the sizes GitHub shows it, especially 24 pixels next to
repository names.

Scotty and Carnegie Mellon's other names and marks belong to the university;
the organization's BSD license doesn't cover them.
