# Branding

Sources for the org's picture, kept here so a change doesn't start from
scratch.

| File                 | What It's For                                                                                                                                                                                                                                                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cmu-web-avatar.svg` | The source: Scotty in a browser window. The Scotty artwork is PlaceMellon's [`assets/scotty-bust.svg`](https://github.com/cmu-web/cmu-web-placemellon/blob/main/assets/scotty-bust.svg) (the original black with the red scarf), with his back continued past the left edge. |
| `org-avatar.png`     | The 500x500 rendering of the source, uploaded as the [org picture](https://github.com/organizations/cmu-web/settings/profile).                                                                                                                                               |

Check a new version at the sizes GitHub shows it, especially 24px next to
repository names. Scotty and Carnegie Mellon's other names and marks belong
to the university; the org's BSD license doesn't cover them.
